# Drop clips here

This branch is a loading bay, not part of the site. Nothing here is published.

## How to use it

1. Click **Add file → Upload files** above, while you are inside this `raw/` folder.
2. Drag in as many clips as you have. You can do a few at a time.
3. Name each file exactly as it appears in the checklist, for example
   `back-squat-gym.mp4`.
4. Commit.

Then tell Claude. The clips get compressed for the web, a still is pulled from
each one for the grid, and the finished versions are committed to `main`.
This branch is deleted afterwards so the raw footage never lands in the site's
history.

## Before you upload

- Trim each clip to **10 to 20 seconds**. One or two clean reps is plenty.
- Export at **1080p**. Anything larger is thrown away in compression.
- Sound is stripped, so do not worry about noise in the gym.
- Frame the **whole body**, with enough room that nothing leaves the shot at
  the bottom of a rep.

Partial batches are fine. Whatever is not uploaded yet keeps showing
"Clip in production" on the page, and nothing breaks.
